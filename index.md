# Personal Calendar Sync

Personal Calendar Sync is a private scheduling assistant operated for its owner's personal use. It helps organize Google Calendar events and Google Tasks, including work deadlines, personal activities, and training schedules.

The owner authorizes access through Google OAuth. The assistant runs through Codex and the locally installed Google Workspace CLI (gws). It is not a public registration or multi-user service.

Only the owner's authorized account is intended to use this application. This public website provides application information only; it does not display calendar entries, tasks, training details, or credentials.
